no Rust counterpart because Rust skill expansion is synchronous.

`SkillWalkOptions.realpath` has no consumer: Rust `build_skill_allowed_set` canonicalizes only the top-level
sources and does not walk subdirectories, so only those become roots. senpi adds the realpath of every walked
directory as a root. This difference predates v2026.10.27-2; the memo (`memoized_realpath`) only dedupes the
top-level canonicalize calls.
