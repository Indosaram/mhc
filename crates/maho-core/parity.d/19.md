## Notes

- Support modules without a senpi counterpart under the crate's source root: `src/frontmatter.rs` ports
  `packages/coding-agent/src/utils/frontmatter.ts` and `src/source_info.rs` ports `core/source-info.ts`
  (owned by todo 21's remainder, ported here because skills, prompt templates and the resource loader
  depend on it). `crate::paths::resolve_path`/`lexical_resolve` and `crate::config` already existed from
  todo 16; `get_package_dir`, `get_readme_path`, `get_docs_path` and `get_examples_path` were added to
  `config.rs` for `system-prompt.ts`.
- New crate dependencies: `maho-tui` (the `tui.*` keybinding table and `KeybindingsManager`),
  `serde_yaml =0.9.34` (frontmatter) and `ignore =0.4.33` (gitignore semantics, already in the lockfile
  as a maho-grep dependency).
- Known text deviations, all in error/diagnostic strings produced by third-party parsers:
  `parse_frontmatter` reports a `serde_yaml` message where senpi reports the `yaml` npm package's, and a
  failed skill read reports `std::io::Error`'s message where senpi reports Node's `ENOENT: ...` text.
  Diagnostic shape, type, path and the skip decision are identical.
- `compaction/utils.rs` carries `normalize_patch_text`, `strip_heredoc` and `extract_patched_paths`,
  which senpi imports from the gpt-apply-patch extension. The Rust extension crates depend on maho-core,
  so the helper is duplicated here and the two copies must stay in sync.
- `compaction/lifecycle.rs` compares abort controllers through `CompactionAbortController`, which adds
  the reference identity JS gets from `===`; maho-ai's `AbortSignal` exposes none, so
  `has_current_signal` takes the controller rather than the signal.
- `compaction/utils.rs::strip_heredoc` reimplements the senpi regex by hand; the common
  `cat <<'EOF' ... EOF` shape is covered and a non-matching input is returned unchanged.
- `dynamic_prompt/workstation.rs` collects host facts from `/proc/cpuinfo`, `/proc/sys/kernel/osrelease`,
  `uname -r` (macOS) and `TERM_PROGRAM`/`TERM`, mirroring the Node calls senpi makes.
