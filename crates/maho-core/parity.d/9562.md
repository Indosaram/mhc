# 9500: single exec implementation (parity closure, 2026-10-14)

Pinned source: senpi fe8c564bf33a2cbbdbbba99c9bd8b45b21e37407.

`src/exec.rs` no longer carries its own subprocess runner (which had no abort signal, hung on
descendants holding pipes, and returned empty output on timeout). It re-exports
`maho_ext_host::exec::exec_command` with `maho_ext_api::{ExecOptions, ExecResult}`, the same
implementation behind `ctx.exec`: abort signal, SIGTERM then SIGKILL after 5s, exit/stdio grace,
and partial output on timeout. The ext-host runner now also strips `__PI_INTERNAL_SPAWN` from
children. The explicit per-call `env` option was dropped because upstream `ExecOptions` has none.
This supersedes the exec.ts row in fragment 16; its three unit tests are covered by
maho-ext-host `tests/exec.rs`.
