# 9812 — reserved-keyword painting for O06 prohibitions

The `reserved-keywords.ts` surface keeps its senpi pin. In `src/reserved_keywords.rs`
the skill-paint pass now uses the same advice masking as OmO v5.1.81's
`packages/omo-senpi/src/components/skill-pointers/strip-quoted-regions.ts`.
This keeps `ulw-loop` and `ulw-plan` inside a prohibition from painting while a
later positive request still paints at the correct UTF-8 byte offset.
`tests/keyword_paint_arm_parity.rs::advice_leaves_only_the_requested_keyword_painted`
exercises the editor's actual span API.
