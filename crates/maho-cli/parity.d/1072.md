Plan Todo 1072 repairs the `MemoryRuntime::reconcile_worker` logger wiring in `crates/maho-cli/src/cli/memory_runtime.rs`.

## Details
In pinned upstream `packages/omo-senpi/src/components/memory/identity-runtime.ts:138`, `reconcile()` delegates to `reconcileReflectionRuns` without passing a logger:
```typescript
async reconcile(): Promise<void> {
  await reconcileReflectionRuns({ identity: asMemoryIdentity(identity), reservation: store, launch })
}
```
Likewise, native `crates/omo/components/maho-omo-memory/src/identity_runtime.rs:44` passes `None`:
```rust
crate::worker::run_reconciliation::reconcile_reflection_runs_with_options(
    &crate::worker::run_finalization_types::RunFinalizationContext {
        identity: &identity, reservation: self.store.as_ref(), launch: Some(launch), now_ms: now
    },
    recovery,
    None,
    true,
).await
```
Native `crates/maho-cli/src/cli/memory_runtime.rs` previously constructed `sweep_logger = ReflectionSweepWarnLogger(self.host.warn.as_ref())` and passed `Some(&sweep_logger)`. Under a clean/fresh HOME directory where the git memory repository at `paths.repo` has not yet been initialized (due to upstream's intentional first-write lazy initialization seam), `sweep_reflection_orphans` fails to execute `git worktree list --porcelain` on the non-existent repo directory, causing `warn_sweep_failure` to log `Reflection orphan sweep failed: ... fatal: cannot change to '.../repo'` to the host warning sink (`stderr`).

Passing `None` as the logger argument in `reconcile_worker`:
1. Restores exact 1:1 behavioral parity with upstream `identity-runtime.ts:138` and `maho-omo-memory/src/identity_runtime.rs:44`.
2. Eliminates false-positive stderr warning logs on fresh HOME during startup.
3. Preserves full reconcile error propagation via `?` on `reconcile_reflection_runs_with_options`.
4. Preserves deferred scheduler contention handling (`defer_on_scheduler_contention: true`).
