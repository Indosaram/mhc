`--session-runtime worker|in-process` is parsed and resolved (`args::resolve_session_runtime`, senpi `cli/args.ts:93`). A resolved `worker` runtime (the default for stdio hosts) builds the host with `host_runtime::create_worker_host_core`, which installs `maho_rpc::worker_session_registry::WorkerSessionRegistry` (senpi `createHostCore` selecting `WorkerSessionRegistry` when `workerConfiguration` is passed, main.ts:1119-1148). Each opened session runs in its own process: this binary re-entered under the internal `rpc-session-worker` role (`maho_rpc::session_worker::run_session_worker`, senpi `modes/rpc/session-worker.ts`). An `in-process` runtime keeps the unchanged in-process `RpcSessionRegistry` host. Rust tests: `tests/session_runtime_worker.rs`.
