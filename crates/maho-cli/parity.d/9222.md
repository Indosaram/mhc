# Native builtin factory metadata correction

`src/cli/default_extensions.rs` constructs builtin factories with `SourceInfo.source = "builtin"` and their actual factory path. This satisfies the reserved `tool_search` registration boundary in `maho-ext-api` and aligns with the source metadata supplied by `src/cli/extension_registry.rs`.

The existing `tests/default_extensions.rs` factory-loading regression now checks the machine-consumed source and path fields for the tool-search factory. Installed MCP search and call acceptance is still pending against the rebuilt packaged binary; earlier receipts failed on the previous binary.
