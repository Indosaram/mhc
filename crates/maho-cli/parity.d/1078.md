## Details
Connects live `resolve_write_notice_enabled` in `MemoryRuntime::build_static_options` to `MemoryStaticOptions.write_notice`. The resolver:
1. Reads current active identity via `this.active_identity()`.
2. Inspects live runtime memory settings (`this.settings()`).
3. Evaluates per-agent `agents[identity].write_notice.enabled` override if present, falling back to global `write_notice.enabled` (defaulting to `true` on unreadable config per upstream).
4. Evaluates dynamically per call rather than latched at registration so setting changes and identity switches take effect on the next write tool call without a restart.
