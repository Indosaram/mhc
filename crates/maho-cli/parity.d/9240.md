# Interactive component diagnostics

| TS path | Rust path | TS tests | Rust tests | status |
|---|---|---:|---:|---|
| main.ts | src/cli/runtime.rs | 0 | 0 | done |

Interactive stderr takeover precedes native factory initialization and is restored on every runtime exit. Native factories can emit component diagnostics before interactive entry. The main.ts dispatch to interactive-mode.ts is implemented by src/cli/interactive_entry.rs; runtime owns stderr takeover across startup, binding, turns and shutdown, and entry no longer restores it prematurely.

Real old-binary startup reproduction is captured in `.omo/evidence/hang-fix/harness-smoke2`. Rebuilt package acceptance must establish hidden log presence and terminal absence, not merely a clean transcript.
