# 9811: O09 doctor category coverage (omo v5.1.81)

Upstream `packages/omo-native/bin/lib/category-coverage.js` delegates coverage to the task runtime. Native `src/cli/doctor.rs` now obtains its builtin names from `senpi_task::category::BUILTIN_CATEGORY_DEFAULTS` rather than a second list. Custom names are still merged and disabled categories skipped. This avoids omitting either deep lane from the reported denominator.

`doctor_counts_all_ten_builtins_and_only_exact_gpt_lanes` exercises the coverage formatter with synthetic Astra-only, Sol-only and Fast-only OpenAI registries, without using credentials or a real agent directory. Rust tests were not executed in this lane.
