- cross-project-session: senpi's async `confirm` is a blocking callback here. `cli/runtime.rs`
  (drift-owned) still prints its own copy of the non-interactive fork text and does not call this
  module yet.
- session-opening and process-identity take their probes as arguments. They are not called from
  `main.rs`/`runtime.rs` (drift-owned) yet.
- continue-moved needs core `moved-sessions.ts` `listMovedSessions`, which has no Rust port; its
  prompt half is `confirm_same_repository_rebind` in `cross_project_session.rs`.
- host-session-command needs `modes/rpc/host-session-runner.ts` (maho-rpc lane), which has no Rust
  port.
- experimental/micro is built on `pi-agent-core/experimental/pico3` (the Harness/JsonlStorage
  envelope runtime), which no crate ports yet. Rows 90 and 92 are requeued.
- utils/zip.ts is named `zip_archive` so it does not shadow the `zip` crate.
