Scripted headless desktop backend for tests: serves displays, windows, and
accessibility trees from a JSON `FakeScenario`, records every side effect into
a `RecordingSink`, injects per-method failures and delays, and ships a
`FakeClock` for heartbeat tests. Touches no OS API.
