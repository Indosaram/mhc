## Divergences from the upstream bytes

- `error.rs`: mhc base also lacked `InputBusy`, `ControlRequired`, `CaptureUnavailable` (-32021..-32023); they are added as enum codes and constructors (`input_busy`, `control_required`) so the four amendment-1 codes keep upstream numbers -32024..-32027. `CaptureUnavailableData` / `capture_unavailable(reason)` are not ported (no capture-state refusal in mhc yet).
- `schema/engine.schema.json` is hand-applied (no cargo here); `schema_is_fresh` regenerates it if schemars output differs.
- Conformance fixtures `ax-unconfirmed.json`, `error-codes-amend-1.json`: upstream bytes minus the single `"cursorOverlay": false,` line in the `session.open` capabilities (mhc has no cursor overlay, and `DesktopCapabilities` is `additionalProperties: false`), the same adaptation as mhc's existing conformance fixtures. Every other byte is identical to upstream.
