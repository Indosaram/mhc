X11 native desktop backend over pure-Rust x11rb (never links libX11/libxcb):
RandR display enumeration, EWMH window enumeration, root-window
`GetImage` capture, XTEST/`XSendEvent` input with the `_NET_ACTIVE_WINDOW`
focus guard, AT-SPI accessibility, and the XI2 raw-key kill switch (the
`Global` stop path).

Scope: SOURCE AUTHORING AND IMPORT. Imported file-for-file from native upstream Rust source.
Preserves exact upstream behavior, module structure, and test coverage.
No claims of live nonhost behavior: this crate targets `cfg(target_os = "linux")` and requires X11/XTEST/XI2 runtime environments for live operation. No Cargo build/test commands executed before workspace assembly.
