Per-name N/A (TS-only):
- createExtensionRuntime, discoverAndLoadExtensions, loadExtensionFromFactory, ExtensionFactory, InlineExtension:
  jiti/TS module loading; native extensions are statically linked (NativeInlineExtension, maho-ext-host loader).
- Bash/Edit/Find/Grep/Ls/PowerShell/Read/Write/Custom ToolCallEvent and ToolResultEvent: TS discriminated
  narrowings of one event; native keeps ExtensionEvent::ToolCall / ToolResult with `tool_name` and typed
  inputs (BashToolInput etc.).
- ExecuteToolHandler, SetModelHandler, NavigateTreeHandler, SwitchSessionHandler and the other `*Handler`
  function-type aliases: native exposes them as ExtensionActions / ExtensionContextActions trait methods
  (execute_tool, set_model, navigate_tree, switch_session).
- ContextWithSystemEvent: senpi context-dispatch.ts event; native has no context_with_system dispatch path
  (EventKind::Context only), so no event type is mirrored without its dispatcher.
- ExtensionToolContext: senpi `ExtensionContext & { tools, executeTool }`; native passes ToolContext plus
  ExtensionActions::execute_tool, no merged struct.
- ExtensionUIContext: native ExtensionUi / ExtensionUiActions traits.
- ExtensionVirtualModel: needs registerVirtualModel on ExtensionApi, which maho-ext-api does not carry
  (virtual models are maho-core virtual_models.rs).
- AppKeybinding: `keyof AppKeybindings`, a TS key type; native keybinding ids are maho-core keybindings.rs.
- NormalizedBuildSystemPromptOptions: TS intersection type over BuildSystemPromptOptions (maho-core system_prompt.rs).
