# 9812 — typed access to model-facing custom message content (O06)

`src/types.rs` re-exports the existing agent message variants and custom
message content type. The model-aware context handler in `maho-ultrawork`
can select its whole prompt without a JSON round trip or a new wire type.
This is native support for `packages/omo-senpi/src/components/ultrawork/index.ts`
at v5.1.81; there is no change to the senpi extension event schema.
