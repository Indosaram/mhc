Added ExtensionAPI contracts: provider registration/unregistration, exec, executeTool,
shortcuts, lazy activation, Markdown transformers, read classifiers, model selection,
active tools, commands, session name, thinking levels, fast-mode indicator, labels and
RPC. ExtensionContextActions and ExtensionCommandContextActions have typed members
for the upstream context and navigation operations; the runner can bind both. Session
replacement callbacks and command contexts are explicit types. Additional UI actions
cover questions, terminal input, working indicators, editor factories, autocomplete,
themes and tool expansion.

Provider registrations reach the existing ModelRuntime through the minimal adapter in
agent_session_runtime.rs. Queued registration failures are isolated and attributed to
their extension, while later registrations still run. The existing AgentSession does
not yet bind the added ExtensionSessionActions or ExtensionContextActions; the types
are not proof that those session operations work in the CLI.
