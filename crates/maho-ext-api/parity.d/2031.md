The native MCP snapshot structs and connection/config enums are mechanically
extracted from the existing MCP modules into this shared API module. MCP retains
public re-exports so RPC and the builtin use identical native payload types and
unchanged serde names. This extraction removes the production dependency cycle
interactive -> rpc -> mcp -> tool-search -> interactive. It is not a new protocol.
The originating MCP modules and their tests retain their existing mappings.
