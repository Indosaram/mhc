Added failed synchronous factory isolation, asynchronous native factories with error
isolation and rollback of shared registrations/subscriptions, signal-aware invocation
contexts with deterministic disposal (including dropped execution futures), protected
builtin shortcut resolution and attributed collision diagnostics, and notice modules.
Async factory panics are isolated during construction and polling. Compaction feedback
inherits the beginCompaction signal within each created context, with explicit signals
taking precedence and separate contexts retaining separate invocation signals.
Task-local kernel capability scopes support nested invocation restoration and are
captured by runner contexts with bound context actions. Unbound contexts and the
actual kernel invocation host still need capability wiring.
Concurrent context reload requests share one host future, and completion releases
the request slot so later requests run again. Reload coalescing still needs command
context and real session host wiring.
Inline native factories preserve one-based unnamed identities, named identities,
load order, and separate hidden-path presentation metadata without changing existing
LoadedExtension constructors.

Remaining: loader discovery/resource diagnostics and full
registration validation; retained failed API invalidation and transactional staging
rather than whole-state rollback; full runner UI prompt
lifecycle and request-local provider preparation;
real session/context/command/UI binding. Notice colors currently consume
ANSI values from the data-only Theme and still need owning-theme conversion plus
golden byte comparison. The original 20b omissions remain unless listed as added here.

Audits cover historical ledger roots, not the entire upstream extension directory.
