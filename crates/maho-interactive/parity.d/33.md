# Todo 33: interactive selectors and dialogs

Pinned source: senpi fe8c564bf33a2cbbdbbba99c9bd8b45b21e37407.

The selector/dialog components render through the maho-tui primitives ported by todo 7
(`Text`, `TruncatedText`, `Spacer`, `Input`, `SelectList`, `SettingsList`) and the interactive
theme from todo 31. Where a senpi component reads a `core/` type that plan todo 21 still owns
(`SessionInfo`, the `SettingsManager` write API, `HTTP_IDLE_TIMEOUT_CHOICES`), this port takes the
same fields through a component-local view type so the component logic stays faithful without
importing an unported module. senpi's module-level `theme` singleton becomes an explicit
`&Theme` argument.
