## Notes for the merge

- `api/cursor-agent.ts`'s HTTP/2 transport is written against `h2` + `tokio-rustls` +
  `webpki-roots` directly (the same stack Node's `node:http2` provides), so the request
  path, header sanitization, Connect framing, exec-channel dispatch, heartbeat and
  stream-health behaviour are ported one-for-one rather than rebuilt on reqwest.
- `agent.proto` carries the JSON-value fields as `bytes` (protobuf-es serializes
  `google.protobuf.Value` before it goes on the wire), so `value_pb.rs` ports that
  well-known-type codec locally; it is the only Rust-only file in this node.
- This branch also merged `sub/12-cursor-pb` (generated prost bindings) and
  `sub/13-cursor-oauth` (`cursor::composer_prompt`, `cursor::selection_descriptor`,
  `cursor::model_capabilities`, `cursor::catalog_grouping`), because `cursor-agent.ts`
  imports both. Three defects carried in by the 13-cursor-oauth WIP were repaired so the
  crate builds and its tests pass: a missing `cursor-variant-aliases.json` data asset
  (copied from pinned senpi, byte-identical), two impossible `Eq` derives on structs with
  `f64` fields, and `level_token_to_thinking_level` missing the `off`/`extra-high` tokens
  the alias data uses. One 13-cursor-oauth test expectation (`gpt-5.1[reasoning=low]`) was
  wrong against pinned senpi, which returns `gpt-5.1-low`; the test was corrected and a
  genuinely bracket-producing case (`[thinking=false,context=1m,effort=xhigh]`) added.
  The sibling's own worktree still carries these defects.
