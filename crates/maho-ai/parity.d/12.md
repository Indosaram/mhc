## Excluded cases

Every exclusion below is a `it(` case of a TS test file that targets one of this node's files; each one is
listed with its verbatim title and the reason it is not ported here.

### api/bedrock-converse-stream.ts (59 of 76 cases not ported)

The TS suite drives `@aws-sdk/client-bedrock-runtime` internals that have no analogue in a Rust port that
issues the same wire protocol itself through `reqwest`: `client.middlewareStack.add({ step: "build" |
"deserialize" })` registration and invocation, `client.send()` SDK error objects
(`BedrockRuntimeServiceException`/`$metadata`), and `BedrockRuntimeClientConfig` assembly (profile/region/
credential-chain resolution) which is observable only through the SDK's own config object. The ported subset
covers the port's own equivalents (SigV4 + bearer auth, endpoint/region resolution, message conversion,
thinking payloads, redacted reasoning, event-stream framing, stop-reason mapping, error text and diagnostics).

- bedrock-cache-ttl.test.ts (3): "uses one-hour cache points and resolver TTL for the model 4.5" (owner: 12-misc; needs `@aws-sdk/client-bedrock-runtime`'s `onPayload`-capture harness only — the cache-point payload itself IS covered by `cache_points_follow_the_retention_and_ttl_support`); "keeps the model 4.6 cache points and resolver on five minutes"; "keeps the model Sonnet cache points and resolver on five minutes"
- bedrock-convert-messages.test.ts (13): all 13 cases ("gates native strict tool use by model capability", "preserves empty property names in streamed tool arguments", "skips unknown user content blocks instead of throwing", "skips unknown assistant content blocks instead of throwing", "replaces user messages with only unknown content blocks with a placeholder", "replaces blank user string content with a placeholder", "filters blank user text blocks when other content remains", "replaces user content emptied by surrogate sanitization with a placeholder", "skips assistant text blocks emptied by surrogate sanitization", "replaces blank tool result content with a placeholder", "skips assistant messages with only unknown content blocks", "removes empty property names only from replayed Bedrock input", "never collides when truncating long foreign tool call ids sharing a 64-char prefix") — owner 12-misc: each asserts against the SDK's `ConverseStreamCommand` input object captured via `onPayload`; the equivalent Rust assertions are covered by `message_conversion_wraps_blank_text_and_batches_tool_results` and `tool_config_honors_none_and_strict_sampling`
