Notes:
- loader.test.ts: five cases are ported; "unrefs loader animation timers" checks Node timer unref, which has no Rust equivalent (the host loop owns the render clock).
- TS test counts are the census counts; Rust counts are `#[test]` functions in the listed file, which may also host tests for sibling TS files.
- sgr-coalesce: the vt100 cell snapshot compares char, fg, bg, bold, dim, italic, underline and inverse; blink, hidden and strikethrough are outside the snapshot.
- terminal.ts: `ProcessIo::size` reads the window size from the saved terminal descriptor while
  fd 1 is redirected to the log (`fd_redirect::redirected_terminal_size`), so a redirect no longer
  reports the log file's (absent) size. The SIGWINCH resize re-emit is not ported.
- layout/tui-render/overlay/viewport-render/alt-screen-search tests replay senpi's
  `waitForRender` as one explicit `do_render` each, and the scrollbar hide timer as
  `fire_hide_timer_if_due(now_ms)`; no case sleeps.
- tests that drive the async provider or timers use explicit clocks (`poll_autocomplete_at`, `poll_terminal_queries(now)`), never sleeps.
