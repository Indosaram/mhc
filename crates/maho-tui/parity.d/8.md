## Notes

- `Editor` reaches its host through `EditorTuiHost` (`request_render`, `terminal_rows`) instead of
  senpi's `TUI`; `TuiBase` exposes no virtual dispatch back to a subclass, so the seam is explicit.
  The host still owns the render clock, which is why the timer-driven autocomplete cases above stay
  unported here.
- `PasteMarkerRegistry` and `ImageMarkerRegistry` keep senpi's registration order (a `BTreeMap`
  keyed by id), so `pasteCounter`/`imageCounter` and the `max(id)` recomputations match exactly.
- `segmentWithMarkers` takes an explicit base segment list (`SegmentRef`) because Rust has no
  `Intl.Segmenter` object; `graphemeSegmenter`/`wordSegmenter` map to `utils::graphemes` and
  `utils::word_segments`.
- Undo attachment payloads cross the seam as `Rc<dyn Any>` (`AttachmentState`) so image bytes never
  enter the editor, matching senpi's opaque `unknown`.
