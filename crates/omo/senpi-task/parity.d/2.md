### N/A

- The `non-finite cost` fixture in run-stats.test.ts feeds `JSON.parse('...1e400')` (Infinity). serde_json rejects 1e400, so the Rust test passes `f64::INFINITY` through `json!`, which serializes to `null`, the only shape a non-finite number can take at the JSON host boundary. The assertion is unchanged: cost omitted, and no `null` in the serialized snapshot.
- `renderer-text` width uses per-char `unicode-width` rather than pi-tui grapheme segmentation. For the ASCII and control-sequence inputs the TS tests exercise, the results are identical.

### Sibling gaps

- `omo-config-core` fails `cargo clippy -D warnings` with 31 lint errors in its own sources (collapsible_if, module_inception, type_complexity, and others). As a result, `cargo clippy -p senpi-task --all-targets -- -D warnings` exits 101 before it reaches senpi-task. senpi-task itself is clean: `cargo clippy -p senpi-task --all-targets --no-deps -- -D warnings` exits 0. The sibling was not edited, per the scope rules.
- `delegate_adapter.rs` is a private adapter for delegate fallback entries that `delegate-core` does not export in the shape category resolution needs.
