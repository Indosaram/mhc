Wayland native desktop backend, pure Rust (no libxkbcommon, no PipeWire):
libei input through `LIBEI_SOCKET` or a RemoteDesktop portal session
with group-aware XKB keymap resolution, Screenshot-portal capture, AT-SPI
accessibility, honest background-only capabilities, and the
GlobalShortcuts-portal stop path.

Scope: SOURCE AUTHORING AND IMPORT. Imported file-for-file from native upstream Rust source.
Preserves exact upstream behavior, module structure, and test coverage.
No claims of live nonhost behavior: this crate targets `cfg(target_os = "linux")` and requires Wayland/portal/EIS/PipeWire/AT-SPI runtime environments for live operation. No Cargo build/test commands executed before workspace assembly.
