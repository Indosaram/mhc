# 9501: Windows parent watchdog

| Upstream | Native | Status |
|---|---|---|
| `server.ts` `isProcessAlive` (`process.kill(pid, 0)`; win32 reports `ESRCH` once the process exits) | `watchdog.rs` `platform::probe` (`#[cfg(windows)]`: `OpenProcess` + `GetExitCodeProcess`, `ESRCH` for an unknown or exited pid) | done |
| `process.ppid` | `watchdog.rs` `platform::parent_process_id` (`#[cfg(windows)]`: ToolHelp process snapshot) | done |

Supersedes the Windows note in `2.md`: the parent watchdog now fires on Windows, so ast-grep and lsp MCP children exit with a dead parent. Any other `OpenProcess` error is reported as its own code, which `classify_probe_error` keeps as alive.
