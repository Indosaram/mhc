### Upstream Behavior to Native Implementation Mapping

1. **Synchronous Credential-Gated Registration**:
   - `has_xai_credential`: Synchronously probes `<agentDir>/auth.json` at extension load time for `xai` entries with type `oauth` or `api_key`. Falls back to non-empty `XAI_API_KEY` if `auth.json` does not exist. Fails closed on invalid JSON or unknown types.
   - `create_x_search_component`: At extension load (`register`), skips registration silently when no credential exists (matching upstream optional debug-channel contract). When credential is connected, registers `x_search` tool definition into `ExtensionApi` and listens on `ResourcesDiscover`.
2. **Refresh-Aware Bearer Resolution**:
   - Inside tool execution (`execute`), the bearer is resolved on every call via `resolve_xai_bearer` through the live `context.model_registry` (`get_stored_credential_type` and `get_provider_auth`), never caching across calls, so mid-session token refresh is picked up. Falls back to trimmed `XAI_API_KEY` in environment.
3. **Wire Request & Response Normalization**:
   - `build_x_search_request`: Constructs xAI responses API payload using carrier model (default `grok-4.20-0309-non-reasoning` or `grok-4.6` with reasoning `low`, overridable by `OMO_X_SEARCH_MODEL`), bounding envelope to 1 turn, 4000 max output tokens, `parallel_tool_calls: false`.
   - `requestParams` & `From<&XSearchParams>`: Preserves explicit boolean `enable_image_understanding: Some(bool)` and `enable_video_understanding: Some(bool)` (including `Some(false)`).
   - `perform_x_search`: Accepts native `maho_ai::utils::abort::AbortSignal`, selects on `signal.cancelled()` alongside deadline timer, handles pre-aborted signals immediately, supports custom endpoint override, and maps status codes (401/403 -> AUTH, 429 -> RATE_LIMITED with `retry-after`, 200 non-JSON -> PROTOCOL, timeout -> TIMEOUT, caller abort -> UPSTREAM "cancelled by the caller").
   - Parameterized cases: Expanded all `it.each` loops into 34 distinct native test cases covering every HTTP failure status code (401, 403, 500, 503) and every error code format string individually.
   - `normalize_x_search_response`: Extracts and dedupes tweet IDs across URL citations in annotations, tweet URLs in message text, and top-level citations. Extracts server query tool calls and usage ticks.
4. **Validation Exact Semantics & Priority**:
   - Evaluates in identical upstream order: non-object -> blank query (`query must not be blank`) -> handle exclusivity (`allowed and excluded handles are mutually exclusive`) -> handle count limit (`{key} cannot contain more than 20 handles`) -> ISO date validation (`{key} must be a valid ISO calendar date`, including JavaScript `Date.UTC` year 0..99 offset check and strictly digits) -> date range (`from_date must be on or before to_date`) -> TypeBox schema check (`Parameters failed validation`, with query length measured in UTF-16 code units).
5. **Conditional Skill Contribution & Denylist**:
   - Emits `ResourcesDiscoverResult` containing `skill/SKILL.md` only when xAI credential is present.
   - Uses `maho_omo_bundled_skills::resolve_contributed_skill` so that existing host-loaded `x-search` skills take precedence (yielding without error) and `disabled_skills` denylist hides the skill.
