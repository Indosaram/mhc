## Partial details

- `index.ts`: task/task_send/task_cancel/task_output definitions use native
  `ExtensionApi` and public engine execution factories. Full factory registration
  requires the completion-observing store seam. Abort/progress bridging and the
  skill invocation policy wiring are not complete.
- `engine-runners.ts`: agent resolution and memory-tool exclusion list are
  ported. Production RPC spawning and faux_rpc_child require todo 36. In-process
  session binding is not assembled here.
- `dag-runtime.ts`: checkpoint interception has the same concrete-store issue
  as the task engine. Scheduler lifecycle, recovery and activity RPC composition
  remain unported. The tool's optional wait/cancel seams preserve the source's
  behavior when no scheduler is wired; this is not production scheduler wiring.
- `dag-tool.ts`: action implementation is present. Full TypeBox description
  metadata and differential schema recording remain; schema shape is present.
- Widgets: timer injection, below-editor placement, session scoping and activity
  adapters are ported, but runtime registration/default host timers and the full
  upstream lifecycle test matrices remain incomplete.
- `renderers.ts`: typed rendering helpers are ported. Native message renderer
  registration/deserialization and generated golden comparison remain incomplete.
- `reload-guard.ts`: evaluation and manager adapter are present; event wiring
  remains incomplete.
- `task-rpc-codec.ts`: send/cancel/output request parsers are ported. Snapshot
  bounding, live progress projection, and bounded output are not yet ported.
- Remaining `-` modules have not been ported. They are not claimed implemented
  merely because upstream engine primitives exist.
- No `examples/faux_rpc_child.rs`: explicitly deferred to todo 36 as required.
