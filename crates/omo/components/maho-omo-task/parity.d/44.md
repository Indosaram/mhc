## Partial details

- `index.ts`: task/task_send/task_cancel/task_output definitions use native
  `ExtensionApi` and public engine execution factories. Full factory registration
  requires the completion-observing store seam. Abort/progress bridging remains
  incomplete. The tracker implements the public spawn policy seam using native
  gate and canonical review helpers; full component construction remains partial.
  Native registration fragments now preserve both true flag defaults, explicit
  host overrides and the removed team_wait hint without restoring that tool.
- `engine-runners.ts`: agent resolution and memory-tool exclusion list are
  ported. The in-process runner factory binds the parent registry and an injected
  child session constructor; native runner options still lack the live shared
  tools getter. Production RPC spawning and faux_rpc_child require todo 36.
- `dag-runtime.ts`: checkpoint interception has the same concrete-store issue
  as the task engine. Scheduler lifecycle, recovery and activity RPC composition
  remain unported. Durable 1000-event page publication preserves cursor and
  callback order with panic-isolated listeners; its real journal test crosses
  the page boundary. Scheduler callbacks share the durable cursor and deduplicate
  replay per run. The tool's optional wait/cancel seams preserve the source's
  behavior when no scheduler is wired; this is not production scheduler wiring.
  ChildProgress telemetry projection is ported with the unsequenced RPC schema;
  subscription ownership remains blocked by runtime composition APIs.
  Shared skill materialization now binds the native materializer to the task
  loader and runtime cwd at creation; real manager reuse retains its manifest.
  This does not close the blocked scheduler dispatch integration.
- `dag-tool.ts`: action implementation, TypeBox description metadata and exact
  anyOf literal union shape are ported. Complete parameters compare against
  pinned upstream schema generated by tools/golden/task-44-schema.mjs.
- Widgets: timer injection, cancellable native HostTimers, below-editor placement,
  session scoping and activity adapters are ported, but runtime registration and the full
  upstream lifecycle test matrices remain incomplete.
  Live child subscriptions now exercise independent latest tool activities
  and disposal. Status goldens include resolved effort, empty effort, detached
  residency, description priority, wide progress and legacy model cases.
- `renderers.ts`: typed rendering helpers and native message renderer
  registration/deserialization are ported. Completion components render at the
  requested width. Expanded upstream fixtures now cover nine renderer cases
  at widths 40, 54, 80, 120 and 140, including statistics, long continuation
  and CJK control sanitation (task-44-renderer-expanded.md).
- `category-unavailable-warning.ts`: planner decoration, once-per-session/category
  suppression, per-category/global precedence and structured payload are ported.
  Native UI/custom-message delivery is ported and tested with and without UI,
  without steering or triggering a turn. `compose_task_engine` installs the
  decorator over the real planner; `tests/category_warning.rs` now exercises
  that assembly through registered task tools with an empty registry, preserving
  manager failure fields and the tool's plan_error projection before any runner
  starts. Full frozen and exact-SHA gates remain required; this row is not blocked
  by the protected store observation contract.
- `resumption-channel-emitter.ts`: count-change publication, start/shutdown state,
  channel filtering and payloads are ported through a synchronous manager seam.
  Async owned-member resolution and queued operation semantics remain incomplete.
- `reload-guard.ts`: evaluation and manager adapter are present; event wiring
  is registered by the event bridge. Full production component registration
  remains blocked by the manager store seam.
- `task-rpc-codec.ts`: send/cancel/output request parsers are ported. Snapshot
  bounding, live progress projection, and bounded output are ported with adapter
  regression tests. The error-delivery increment covers every pinned codec
  operation through native parser/snapshot tests and registered invalid-request
  handlers, including integral decimal JSON tail counts and optional zero fields.
  See `.omo/evidence/task44-error-delivery-matrix.md` for execution and remaining
  gates. UTF-16 truncation cannot represent an isolated half-surrogate in a Rust
  String; boundary cuts retain the preceding complete scalar instead. This
  representation deviation is explicit, not exact split-surrogate parity.
- Remaining `-` modules have not been ported. They are not claimed implemented
  merely because upstream engine primitives exist.
- No `examples/faux_rpc_child.rs`: explicitly deferred to todo 36 as required.

## Test inventory

behaviors across commands, formatting, render sanitation, request validation,
planner resolution, and a real file-backed DagManager. These are a subset of
the upstream component matrices, not a claim that all TS tests are ported.
The explicit completed test rows cover only the named source cases. Missing
integration tests are not relabeled N/A, and production partial rows remain open.
