The bundled `omo-memory-mcp.js` entry (`plugin/scripts/build-extension.mjs:52-53`) is served by the
native binary itself behind the hidden `--omo-memory-mcp` argv role (`maho-cli/src/main.rs`), so
`memory.tool_exposure: "search"` registers `omo-memory` with `exposure: search, enabled: true` and
the tools reach the model as `mcp_omo-memory_memory` / `mcp_omo-memory_memory_apply_patch` through
tool_search. The server writes the IC-17 tool receipt via `tool_receipts::write_tool_receipt`, which
`soul_notice.rs` consumes on the matching `mcp_omo-memory_*` tool_result; `nudge_wiring.rs` injects
the provenance (identity, repo path, toolCallId) the server reads. Direct exposure is unchanged.
