## Bounded adaptations (no behavioral improvement)

- **`ctx.logger.debug?.(…)` -> `logger.info(…)`.** The native `maho_ext_api::ComponentLogger` has no
  `debug` method (`crates/maho-ext-api/src/types.rs:727`). Mapping the optional debug diagnostic onto
  `info` follows the established native convention (`maho-omo-config-watch/src/index.rs:32`:
  "`Debug` has no logger method, so it maps to `info`"). Message text and the `{component, hidden}`
  detail object are upstream's verbatim.
- **`resolveContributedSkill(options.path())` -> eager `path: PathBuf`.** Upstream takes a callback
  only to defer computing the path past the `disabled_skills` check; the native caller supplies a
  pure path, so eager evaluation is observably identical (no side effect is skipped or reordered).
- **`HostCommandInfo` lives in `contributed_skill.rs`.** Upstream declares the narrow
  `HostCommandInfo` in `skill-commands/bare-skill-command.ts` and reads the wider `getCommands()`
  entry inline in `contributed-skill.ts`; both are projections of one native `SlashCommandInfo`, and
  the crate dependency direction (`skill-commands` -> `bundled-skills`) puts the shared type in the
  lower crate to avoid a dependency cycle. `skill-commands` re-exports it from
  `bare_skill_command.rs`, so the upstream module surface is preserved.
- **`resolveBundledSkillsDir` candidates.** Upstream's two URL-derived candidates
  (`../skills`, `../../../plugin/skills`) are the native executable-adjacent `skills/` and
  `plugin/skills`, resolved with upstream's first-**existing**-wins rule. A set, non-empty
  `OMO_SENPI_SKILLS_ROOT` is the native packaged-root contract
  (`maho_omo::component_list::skills_root_from`, `maho-cli/src/cli/omo_mount.rs`): it IS the
  session's skills root and wins unconditionally — a misconfigured root is then reported by the
  discover pass rather than silently contributing from a different directory than the one the CLI
  loads skills from. `tests/resources_discover.rs` pins both halves (env wins over an existing
  packaged candidate; env stays authoritative when missing).
