## Porting notes

- `fixtures/workspace-edit-server.mjs` is ported to the Rust binary `src/bin/lsp_core_workspace_edit_fixture.rs`, so there is no JS runtime. The integration tests launch it through `CARGO_BIN_EXE_lsp_core_workspace_edit_fixture`. `tests/support/mod.rs` mirrors `workspace-apply-edit-test-support.ts`.
- `process-signal-cleanup.ts` is ported to `lsp::process_signal_cleanup` using tokio signals. `LspManager::new` installs it and `stop_all` disposes it, matching the TS constructor and `stopAll`.
- TS callbacks/promises map to async fns. `AbortController`/`AbortSignal` map to `crate::abort`. Error messages that callers match on are kept verbatim.

## Sibling gaps

- `mcp-stdio-core`: its JSON parse-error response carries serde's message, which does not echo the offending input. TS `JSON.parse` messages do. `mcp.rs` adds a private adapter, `ParseErrorPayloadReader` plus a `parse_error_response` override, that appends `: <payload>` to the error `data`. The sibling crate was not modified.
