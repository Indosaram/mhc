## Parity Notes

- Pending-stop tombstones: `tombstone_stop` installs a watch-channel listener in `pending_stops` which prevents duplicate concurrent allocations for the same `(root, server_id)` while slow stops settle.
- Idle LRU eviction: `evict_for_admission` iterates non-busy, non-initializing clients with 0 ref count and 0 waiters, selecting the client with minimum `last_used_at` for eviction under cap pressure, preserving busy clients.
- Respawn budget: tracks consecutive dead generations per key up to `CLIENT_RESPAWN_RETRY_LIMIT` (2) and enforces `CLIENT_RESPAWN_COOLDOWN_MS` (60s) before allowing fresh allocations. Resets budget on successful healthy generation.
- Lifecycle test determinism: `tests/lifecycle_latest.rs` replaces fixed 50ms stop sleeps with subscribed exact stop-release gates (`StopGateRegistry`) and race-free `EventLog` with bounded waits, completely eliminating fixed sleeps while strictly preserving exact upstream assertions.
