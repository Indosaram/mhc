# Todo 2003: latest plan checklist grammar port (GAP-1 / T05)

Port of latest plan checklist grammar from `packages/boulder-state/src/plan-checklist.ts` (pinned at adb672532).
Updates include:
- Support for `[~]` in-progress / blocked checkbox status in both structured sections and fallback parsing
- T-prefixed and dotted task keys (e.g. `T1`, `T1.2a`, `T6.3a`)
- Final-wave prefix expansion to support `H` heading items (e.g. `H1`, `H2`) in addition to `F`
- Extended separator parsing: dot + blanks or blanks + optional dash / em-dash (`\u2014`)
- Fallback to simple checklist parsing when structured sections contain 0 tasks but top-level checkboxes exist elsewhere (e.g. Progress Tracker)
