## Counts and divergences

- `stale-work.test.ts` carries 22 `test(` cases; `tests/stale_work.rs` has 23 (the 22 ports plus one
  crate-only case, `transcript_scan_reads_only_the_matching_session_directory`, guarding the session-cwd
  filter). No row is `todo`, no test is skipped.
- Swallow-all-failure is preserved: the Rust reader returns typed `Result` errors (crate divergence 1 in
  `2.md`), so `reconcile_stale_works` catches every error internally and returns `NO_CHANGES` — the
  upstream `try { ... } catch { return NO_CHANGES }` contract. A missing file and an empty `{}` are
  `Ok(None)` → `NO_CHANGES`; a corrupt file is an `Err` → `NO_CHANGES`; a failed write → `NO_CHANGES`.
- `ReconcileStaleWorksOptions` uses `Option` fields with a `Default` (`now: None` = `now_millis()`,
  `threshold_ms: None` = env-resolved, `sessions_directory: None` = skip the transcript scan, `env: None` =
  process env), which reproduces the upstream `options.now ?? Date.now()` defaults.

## Deliberate divergences

`resolve_stale_work_threshold_ms` reproduces the upstream default/override rule for every realistic knob value
(the ported tests cover `900000`, `0`, `soon`, the blank and unparsable forms, and the six-hour default — all
identical). Two numeric edge cases differ because Rust's `f64` parser and JavaScript's `Number()` do not accept
the same input grammar; both are unreachable from the documented `OMO_BOULDER_STALE_WORK_THRESHOLD_MS` usage
and neither changes any recorded behavior:

1. A hex/binary/octal literal (`0x10`, `0b1010`, `0o17`) parses as a number in JavaScript and is rejected by
   `f64::from_str`, so the Rust port falls back to the six-hour default where the TypeScript returns the parsed
   value. The knob is documented as a millisecond count, so a radix literal is out of contract.
2. A fractional knob (`900000.5`) is used as a float threshold by the TypeScript and truncated to an integer by
   the Rust port (`900000`). Activity instants are whole milliseconds, so a sub-millisecond threshold cannot
   change which work is demoted.

No other behavior differs: the staleness rule, the transcript-mtime scan, the demotion plus `stale_since` stamp,
`NO_CHANGES`, and the swallow-all-failure contract are ports of the upstream bodies.
