## Design notes

- Node `path.posix` / `path.win32` are ported privately as `PathOperations::{Posix, Win32}` so discovery stays host-independent.
- Plan `inspect` / `transform` are `Rc<dyn Fn>` closures. Execution delegates to `omo_config_core::run_migrations`, which handles journal, lease, backup and marker.
- `encodeURIComponent` (used for backup directory names) is reimplemented privately.

## Sibling gaps

- None blocking. The `utils::migration` exports (agent/hook/model renames) covered every rewrite this slice needs. Only Node `path` semantics and `encodeURIComponent` were adapted privately, and neither is a `utils` migration helper.
