## Deviation

`run_git_bash_command` observes child exit by polling `try_wait` every 5 ms instead of parking on
Node's `close` event, because `std::process::Child` has no wait-with-timeout and this crate forbids
`unsafe`. The observable contract (`{exitCode, stdout, stderr, timedOut}`, kill on timeout) is
unchanged; the polling interval is not observable.

The Node spawn-failure message (`spawn <path> ENOENT`) is not reproduced verbatim: a failed spawn
surfaces the Rust `io::Error` display text. No pinned test covers that string, and the Node text is
itself host-specific.
