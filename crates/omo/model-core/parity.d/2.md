## Deliberate API adaptations

- `unknown` inputs (runtime model metadata, provider error payloads, suggestion errors) take `serde_json::Value` and follow JS truthiness and `typeof` rules. `JSON.stringify` keeps key order through `preserve_order`.
- `Set<string>` becomes `IndexSet<String>`, which keeps insertion order the way `Array.from(set)` does. `Record` tables become `IndexMap` in declaration order.
- `ProviderCache`/`ConnectedProvidersAdapter` are traits. The module-level no-op defaults are `NoopProviderCache` / `CONNECTED_PROVIDERS_ADAPTER`. TS default-parameter overloads become `*_with` / `*_using` / `*_with_cache` variants.
- `fetchModelCapabilitiesSnapshot` takes an injected `SnapshotFetcher` (RPITIT + `Send`). The crate adds no HTTP client.
- Snapshot token limits are `i64`. The bundled models.dev snapshot has only integer limits (checked across all 2,743 entries).
- `ModelSettingsCompatibilityResult` numeric/thinking fields are `Option<Option<_>>`: the outer `Option` is key presence and the inner one is the (possibly dropped) value, matching the TS conditional spreads.
- Enums replace string unions (`ModelResolutionProvenance`, `AliasSource`, diagnostics sources, `RuntimeFallbackErrorType`, `CompatibilityChangeReason`). `as_str()`/serde give the TS wire strings.
