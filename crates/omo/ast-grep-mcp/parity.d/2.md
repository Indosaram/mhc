# ast-grep-mcp parity

Source: `oh-my-openagent/packages/ast-grep-mcp/src` (12 test files, 197 `it` cases).
Rust: `crates/ast-grep-mcp` (lib + `ast-grep-mcp` stdio binary).

Live tests that need a real `sg` run against `/opt/homebrew/bin/sg` and return early
when it is absent, mirroring the TS `describe.skipIf(!SG_AVAILABLE)` gates.
