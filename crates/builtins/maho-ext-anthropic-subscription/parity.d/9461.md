The regression exercises request environment projection through the native
stream and a real fake CLI child: the request OAuth token is forwarded, the
host `PATH` takes precedence, and request `CLAUDE_CONFIG_DIR` and
`NODE_OPTIONS` are dropped. The child turn is bounded and the resident registry
is explicitly closed for cleanup.
