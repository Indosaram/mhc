Account context travels with each attempt rather than an object-keyed WeakMap;
the tests assert plain account labels, source attribution and digested directory
logging. Divergence reports field paths, not values: tests cover block identity,
nested arrays, sorted opaque keys and the recursion cap. The cwd guard rejects
missing, empty and relative paths rather than falling back to the host cwd.
These source mappings correct the stale missing-file census, and do not replace
the final integrated test and real-surface gates.

## sync-5152 parity mappings: anthropic subscription extension helpers

- `auth-lane-boundary.ts`: Upstream extracted this boundary module to support test seams (`overrideAuthLaneBoundary`, `resetAuthLaneBoundary`) for mocking credential store, process environment, clock, and OAuth slot refresh. In native Rust architecture, these boundary parameters (`store: &dyn CredentialStore`, `now: f64`, `refresh: F`, `env: &ProviderEnv`) are injected directly into `refresh_selected` and `ManagedPool` in `src/auth_lane.rs`. Covered in source by 3 in-file unit tests in `src/auth_lane.rs` (`refresh_at_expiry_margin_updates_selected_slot_before_spawn`, `managed_spawn_uses_only_selected_token_and_ambient_keeps_host_auth`, `a_busy_store_keeps_a_live_token_and_adopts_a_sibling_rotation`).
- `cold-seed-images.ts`: Ported in `src/cold_seed_images.rs`. Replays history images capped at `MAX_REPLAYED_HISTORY_IMAGES = 8`, labeling user attachments vs tool outputs and deduplicating identical images. Covered in source by 2 in-file unit tests (`history_images_carry_origin_deduplicate_and_omit_answered_tool_images`, `replay_caps_distinct_images_and_labels_tool_outputs`). Upstream TS vitest suite `packages/coding-agent/test/anthropic-subscription-cold-seed-images.test.ts` contains 11 test cases.
  - Corrected during integration: the decoder now strips the exact ECMAScript whitespace set, including NBSP/BOM and excluding NEL/zero-width space. The new table regression compares canonical decoding and rejects interior padding. Runtime gate pending.
- `context-window.ts`: Ported in `src/context_window.rs` and wired into `src/extension.rs` and `src/options.rs`. Pins `CLAUDE_CODE_DEFAULT_CONTEXT_WINDOW = 200_000` and `LEGACY_LONG_CONTEXT_MODEL_IDS` (`claude-3-7-sonnet`, `claude-opus-4-6`, `claude-sonnet-4-0`, `claude-sonnet-4-5`, `claude-sonnet-4-6`), ensuring only legacy models send the `[1m]` opt-in while native-1M models retain their full window regardless of refusals. Covered in source by 2 in-file unit tests (`only_legacy_ids_use_the_opt_in`, `refusal_caps_only_legacy_ids`). Upstream TS regression suite `test/suite/regressions/3801-subscription-legacy-long-context-catalog.test.ts` contains 1 catalog consistency test.
- `long-context-retry.ts`: Ported in `src/long_context_retry.rs` and used in `src/auth_lane.rs`. Evaluates stream failures via `sdk_failure` and `visible_sdk_message`. Only requests that explicitly asked for the legacy `[1m]` opt-in are eligible for retry; non-legacy requests treat refusal strings as ordinary failures. Retries once at 200k window before any visible content blocks stream. Covered in source by 4 in-file unit tests (`non_legacy_requests_read_the_refusal_as_ordinary`, `only_content_stream_events_are_visible`, `legacy_refusal_closes_the_first_stream_and_retries_once`, `a_non_legacy_request_is_never_retried`). Upstream TS regression suite `test/suite/regressions/3408-subscription-long-context-refusal.test.ts` contains 1 refusal retry test.
- `long-context.ts`: Ported in `src/long_context.rs` and wired into `src/extension.rs`. Manages versioned JSON file persistence (`anthropic-subscription-long-context.json`, `STATE_VERSION = 2`) with atomic temp-file rename, a 6-hour TTL refusal window (`LONG_CONTEXT_REFUSAL_TTL_MS`), and async expiry timers that notify availability listeners. Covered in source by 3 in-file unit tests (`refusal_is_versioned_atomic_and_expires`, `unversioned_state_is_removed_and_ignored`, `an_expired_refusal_offers_the_long_context_window_again`). Upstream TS regression suite `test/suite/regressions/3408-subscription-long-context-refusal.test.ts` contains 6 test cases.
- `refresh-failure.ts`: Extracted upstream from `auth-lane.ts`. In Rust, the logic resides directly in `src/auth_lane.rs` lines 34-60 as `refresh_failure` and `is_grant_rejected`. Preserves rate limits and overloads (429/529), maps 5xx and `TimeoutError` to `server_error:`, and maps invalid grants to `authentication_failed:`. Covered in source by 1 in-file unit test in `src/auth_lane.rs` (`refresh_failures_keep_throttling_and_server_errors_off_the_grant`).
- `seat-digest.ts`: Ported in `src/seat_digest.rs`. Generates stable HMAC-SHA256 account name digests using a CSPRNG-generated salt file (`seat-digest-salt`, 32 bytes) stored in the agent directory with 0600 permissions, atomic creation, and damaged-file replacement. Covered in source by 4 in-file unit tests (`digest_is_stable_private_and_install_scoped`, `damaged_salt_is_replaced_and_unwritable_salt_falls_back`, `simultaneous_creators_converge_without_partial_files`, `hmac_matches_known_key`). Upstream TS vitest suite `packages/coding-agent/test/anthropic-subscription-seat-digest.test.ts` contains 7 test cases.
- `sent-image-slots.ts`: Ported in `src/session_sync.rs` as `image_neutral_content` (lines 75-120). Ensures that historical images and elided placeholder blocks digest identically by extracting image IDs or content hashes, preventing false stream divergence when older images are swapped for placeholders. Covered in source by 1 in-file unit test in `src/session_sync.rs` (`image_elision_preserves_sent_message_hash`).
  - Corrected during integration: normalization now uses maho_core::image_elision_placeholder::elided_image_ids, enforcing the canonical prefix and anchored lower-hex IDs. A regression preserves malformed marker text beside a real image and proves it remains hash-significant. Runtime gate pending.
