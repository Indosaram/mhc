The table uses the built-in crate's senpi source root. The OmO delta is mapped below.

The registered `BeforeAgentStart` hook in `src/index.rs` passes sidecar and
frontmatter declarations from `src/skills.rs` to
`McpService::attach_skill_mcp_servers`. The service resolves project skills
through `src/project_skill_policy.rs` and other skills through `src/skill_server.rs`.
It does **not** instantiate `maho_omo::skill_mcp_manager::SkillMcpManager`.

`packages/mcp-client-core/src/skill-mcp-manager/request-options.ts` maps to
skill-only conversion of `timeout` into the native `requestTimeoutMs` in
`src/skill_server.rs`; catalog, tool, resource and prompt requests then consume
the existing native deadline. General server configuration keeps its own schema.
`http-client.ts` and `timeouts.ts` map to the explicit skill-SSE branch and
bounded GET/POST handshake in `src/transport.rs` and `src/transport_sdk/legacy_sse.rs`.
This is not the event-stream response mode of a Streamable HTTP POST.

`tests/service_skill_sse.rs` exercises service registration for a user skill
sidecar and project skill frontmatter with a loopback server. `tests/skill_server.rs`
covers deadline validation, native option precedence and connection identity.
The shared catalog takes its deadline from the connection, so its pool identity
must distinguish skill declarations with different explicit request deadlines.

Native limits retained: the registered service keeps its existing 30 s request
default and 15 s connect default; explicit native options still take precedence.
Legacy SSE refuses redirects, userinfo and foreign endpoints rather than
forwarding approved headers. Events are bounded to 4 MiB and pending requests to
1,024 per connection. If a POST requires interactive scope escalation, it retires
the session after reauthorization; it does not replay the tool under new credentials.

`crates/omo/maho-omo/parity.d/9813.md`.
