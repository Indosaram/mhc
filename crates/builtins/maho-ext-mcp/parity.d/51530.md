The grant store serializes updates with an OS file lock and publishes private,
fsynced temporary files atomically. Its native observer compares contents and
metadata, rather than carrying the upstream JavaScript watcher object identity.
Project stdio materializes current authority at each start; `open_connection`
passes the current cancellation signal and retains project policy on the real
transport. The transport test exercises grant, revoke and declaration changes.

The real `/mcp` manager constructs `McpManagerView` through the custom UI factory.
Its five event-driven tests cover sanitization with raw-value selection, status
and empty screens, identity-preserving refresh and subscription cleanup,
superseded asynchronous builds/disposal, and narrow layouts/configured keys.
No polling timer drives menu refresh. These mappings are source evidence, not a
claim that the final compiled tests or visual QA have passed.
