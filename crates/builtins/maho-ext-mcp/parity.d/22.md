typed errors; native broadcast event subscriptions now guard callback failures,
dispatch independent futures concurrently like EventEmitter, and drain pending
callbacks when their sender closes. A channel-gated regression proves a pending
callback cannot block the next event. Native error representation remains required
for full wrap.ts parity.

like the pinned SDK's TextDecoderStream; a real HTTP regression covers POST
BOM plus carriage-return delimiters. POST stream resumption, complete SSE parser
compatibility and SDK error reporting remain required.

needs elicitation, progress callbacks,
