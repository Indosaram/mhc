Error kinds and bounded cancellation-aware stream discard are ported. The JS
dump(1024) fast path and explicit destroy lifecycle still need a Rust transport
adapter; current discard takes ownership and drops the stream. Fetching,
document parsing/conversion, tool registration and renderers remain.
Fetcher now implements bounded redirects, headers, response size, cancellation,
timeout and progress. Reqwest does not expose undici statusText/rejection classes;
canonical HTTP reason and Abort transport error mapping are partial. Content-Length
uses strict usize parsing, not JavaScript parseInt. Oversized early rejection drops
instead of bounded-draining the response. These gaps are not hidden as parity.
tool.rs ports format fallback and UTF-8-safe 50KiB output capping only;
tool execution, progress details, HTML conversion and registration remain.
content.rs ports plain-text/markdown normalization only, with explicit JS trim
whitespace. DOM parsing, Readability article extraction and Turndown remain.
