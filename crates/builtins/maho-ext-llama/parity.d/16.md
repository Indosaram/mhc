## Owner-API note

The pinned `syncCatalog` calls `ctx.modelRegistry.refresh({ providers, allowNetwork, signal })`. The
native `maho_ext_api::ModelRegistry::refresh(&self, ModelsRefreshOptions) -> ExtensionFuture<ModelsRefreshResult>`
was added by this todo (ext-api owner) and is implemented by the `ExtensionModelRegistryView` adapter
over the real `maho_core::ModelRegistry`. The llama extension needs no per-session host state: the UI
repaint binding is built from the production `ExtensionUi::request_render` seam, so it stays the
static inline factory (no host-constructed deferred entry).
