The registered search tool calls `config_with_session_logins` with its model,
registry and cancellation signal. Matching login entries resolve their own
endpoint and merged credential headers; keyed entries pass through and missing
logins drop. Five local tests cover both providers, requested-model selection,
keyed pass-through, missing context/login and keyless config validation. This
supersedes the missing implementation recorded in 9700, not the runtime gate.

Google's three tests cover the stable flash alias, explicit model/endpoint
overrides and grounding-only results with first-support snippets. The four
ChatGPT subscription tests cover forced streamed search, configured-header
precedence and account removal, blocked domains, and citation/source deduplication.
The provider dispatcher applies subscription headers and folds the response
stream before normalization. These are source mappings; integrated tests remain
unrun for this candidate.
