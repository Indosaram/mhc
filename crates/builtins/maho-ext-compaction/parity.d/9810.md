# sync-5152 compaction-rest (senpi v2026.10.27-2)

UTF-16 rows: every ported slice cuts at the same UTF-16 unit index as senpi. A cut through a
surrogate pair leaves a lone surrogate in JS; a Rust string cannot hold one, so that half decodes
to U+FFFD, which is also one UTF-16 unit. Lengths, `text.length`-based token estimates, the
`kept N of ~M` counts and truncation-note counts therefore equal upstream exactly; only that one
code unit's value differs (it is replaced on the wire by `sanitizeSurrogates` upstream anyway).
The earlier six-character `\uXXXX` escape changed every downstream length and is removed.

- tool-admission.ts / orchestration.ts: excerpt budget uses senpi's double ratio
  `floor(budget * (len / total))`; `admitContextToolResult` is ported.
- tool-truncation.ts: head 800 / tail 400 units without pair rounding.
- restoration-tracker.ts / resume-slice.ts: JS `trimEnd`/`trim` (ECMAScript whitespace) and the
  ASCII hyphen header.
- overflow-retry.ts: `TRUNCATION_NOTE` accepts only `\d+`; counts print as JS numbers.
- todo-bridge.ts: `readTodoPayload` keeps the ask on legacy `todos` payloads; any numeric
  `capturedAt` is an ask.
- openai-remote-responses-v2.ts / openai-remote.ts: both stream routes await the extension
  `transformPayload` inside the provider's async payload hook and re-validate the result.
