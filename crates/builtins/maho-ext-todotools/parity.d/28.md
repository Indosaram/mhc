transactional operations. Formatting uses the pinned ANSI regex locally because
the shared utils/ansi.ts port is not exposed by the current core crate. Its full
Unicode whitespace edge parity remains unverified. Normalization is implemented;
the remaining upstream parameterized regression cases still need porting.
