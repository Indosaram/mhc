Partial line and paragraph matches use a lossy sample string when the 80-unit
UTF-16 boundary splits a surrogate. Paragraph character detail now converts the
full native cardinality to JavaScript Number without u32 saturation.
Near-duplicate paragraphs also use lossy UTF-16 conversion for tokenization and
samples; unpaired-surrogate handling remains partial.
Remediation truncation uses lossy conversion when its cut splits a surrogate;
the typed native message cannot retain that JavaScript string exactly.
Control-leak positive, negative, grammar and pending-evidence matrices are ported.
Every UTF-16 split and scalar-sized chunking is exercised, including supplementary
offsets, preamble/whitespace limits, family adjacency, quotation fences and flush
latching. The matrix group adds 12 parameterized native regressions.
Rule condition compilation uses regress 0.12 ECMAScript non-Unicode syntax with
UTF-16 pattern units. Manager matching uses UCS-2 tails directly, including a
split-surrogate regression. ASCII word/digit classes, BOM/NEL whitespace,
supplementary dot width, identity escapes, unmatched backreferences and lookbehind
are compared with live JavaScript. Engine diagnostics differ from V8/Bun and remain
partial; no local translation of engine error prose is introduced.
Scope matching uses globset with native ECMAScript fragment translation for
negation, nested extglobs, ranges, POSIX classes, bracket literal alternatives and
singleton braces. Live picomatch matrices and full-crate verification are recorded
in task-26-goal-channels-ttsr-brackets.txt. Plain-group grammar remains local work.
Scope tokens, tool names, condition lists and frontmatter body now trim ECMAScript
whitespace, including BOM and exclusion of NEL, with regressions.
Manager preserves insertion order and bounded UTF-16 stream tails and supports
custom condition compiler injection. Invalid glob compilation preserves public rule
metadata. Upstream matching tests cover source/tool-call isolation, scoped/global
paths, basename fallback, scaled tails, reset, restoration and disabled admission.
Console warning behavior and picomatch glob parity remain partial. Stream-tail
matching no longer replaces split surrogates with U+FFFD.
Rule parser uses serde_yaml; exact npm yaml scalar/duplicate-key semantics and
JavaScript diagnostic parity remain partial. Fallback metadata trim and extension
glob inference use ECMAScript whitespace rather than Rust Unicode whitespace.
Discovery implements sorted project/global precedence and lstat symlink exclusion.
The async entry uses Tokio filesystem operations. The upstream discovery suite is
covered, including malformed/unreachable siblings, nearest ancestor and sorted
origin groups. Default sync/async discovery resolves the operating-system home
through dirs (including passwd fallback), and native startup uses that path.
The cross-turn detector sample omits a scalar split by the 80-unit boundary;
Jaccard cardinality arithmetic now uses the full set lengths as JavaScript Number.
Sample representation remains partial pending exact JavaScript string support.

Entry registers real native hooks, flags, and command. Shared rule-activation
renderer remains unavailable (its crate is empty). The native terminal interrupt-key
listener now uses the shared configurable app.interrupt manager without consuming
input; first-initialization ownership and cancellation are implemented, with a
verified configurable-key regression (task-26-ttsr-terminal-interrupt.txt).
Interactive registration QA remains open. Native FauxSession QA verifies registered status-command
dispatch without a provider turn, clean streaming, and canonical control-token
leak activation plus assistant error-shell replacement. Full settlement/retry and
golden surface parity remain pending. Stream-remediation activation failures
append the canonical ttsr-remediation-error entry without replacing the message;
bound failure-path regression verifies the error entry and original failure message.
Main 068b5f9 binds core and context actions through AgentSession::set_extension_runner;
the former append_entry/send_message/ctx.abort binding blocker is removed. Real
session QA now exercises those bindings for the control-leak remediation path.
Shared context abort currently discards its source argument, so TTSR's system-owned
abort provenance remains partial pending lane 21d.

The scalar scanner accepts UTF-16 units so a split or unpaired surrogate remains
representable, preserving the upstream streaming contract rather than converting
lossily into UTF-8. Full extension acceptance remains pending.
Types retain ownership, retry choices and provider-error errorKind. Coordinator takes the clock
timestamp explicitly for deterministic execution; its caller must supply epoch
milliseconds. No full ttsr acceptance or faux-session parity is claimed.
