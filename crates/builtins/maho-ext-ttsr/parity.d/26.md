Partial line and paragraph matches use a lossy sample string when the 80-unit
UTF-16 boundary splits a surrogate; paragraph character detail clamps at u32::MAX.
Near-duplicate paragraphs also use lossy UTF-16 conversion for tokenization and
samples; unpaired-surrogate handling remains partial.
Remediation truncation uses lossy conversion when its cut splits a surrogate;
the typed native message cannot retain that JavaScript string exactly.
Control-leak algorithm is ported, but the full upstream grammar, negative,
positive and evidence split matrices still need regression test coverage.
The cross-turn detector sample omits a scalar split by the 80-unit boundary and
Jaccard set cardinalities clamp at u32::MAX. These sample/numeric deviations remain
explicitly partial pending exact JavaScript representation support.

The scalar scanner accepts UTF-16 units so a split or unpaired surrogate remains
representable, preserving the upstream streaming contract rather than converting
lossily into UTF-8. Rows marked todo and Extension registration remain unported.
Types retain ownership and retry choices
but the provider-error errorKind accessor is pending. Coordinator takes the clock
timestamp explicitly for deterministic execution; its caller must supply epoch
milliseconds. No full ttsr acceptance or faux-session parity is claimed.
