Only the pure parser/replacement slice is ported. The remaining source files
are deliberately unmapped so the full-crate audit reports the incomplete scope.
types.rs now includes application result, progress, preview, failure and recovery
data contracts. Rendering/theme/state and extension API aliases remain.
workspace.rs resolves absolute/relative paths lexically; relative cwd and empty
filePath node:path.resolve edge cases remain unverified. text.rs uses a direct heredoc scanner;
full JavaScript regex whitespace edge parity remains unverified.
External upstream test suites are not yet fully ported.
Preview-format ports changed-hunk windows, head/tail capping, relative display
paths and unthemed summaries. Render-state cache/in-flight strings and themed
renderToolDiff remain; UTF-16 slicing never emits a lone surrogate in Rust.
Display-path relative cwd and normalization of filePath dot segments unverified.
extension.rs ports GPT family/API gating, tool-name replacement and failure
inspection. Stateful registration/lazy activation/event wiring still requires
missing runtime deferred ToolDefinition registration and renderer contracts.
apply.rs ports nonempty verification, compact result, authoritative mutation
queues, atomic writes, application/recovery loop and fallible progress callbacks.
Atomic-write injection tests, localeCompare queue ordering and complete Node
errno/message parity remain unverified; native tool wiring remains open.
patch-diff uses authoritative maho-tools unified patch with full context and
retains identical-content rows explicitly; CRLF diffLines equivalence unverified.
preview ports snapshot/binary detection, add/delete/update/move previews and
per-file error discard. Pending tool updates and full source tests remain.
tool.rs ports result-preview ordering/truncation/byte caps and execution-result
assembly. Native definition, freeform format, callbacks and renderers remain.
