Only the pure parser/replacement slice is ported. The remaining source files
are deliberately unmapped so the full-crate audit reports the incomplete scope.
types.rs now includes application result, progress, preview, failure and recovery
data contracts. Rendering/theme/state and extension API aliases remain.
workspace.rs resolves absolute/relative paths lexically; relative cwd and empty
filePath node:path.resolve edge cases remain unverified. text.rs uses a direct heredoc scanner;
full JavaScript regex whitespace edge parity remains unverified.
External upstream test suites are not yet fully ported.
Preview-format ports changed-hunk windows, head/tail capping, relative display
paths and unthemed summaries. Render-state cache/in-flight strings and themed
renderToolDiff remain; UTF-16 slicing never emits a lone surrogate in Rust.
Display-path relative cwd and normalization of filePath dot segments unverified.
