  `process_start_time_ms` in maho-tool-child group_ownership.rs:288/337 (also
  crates/maho-cli/src/cli/schedule_watch.rs:107).
- `lease-file.ts`: the native lease publishes with O_EXCL `create_new` and reclaims dead/corrupt
  records in src/manifest_lease.rs:12; it has no token/reclaim-lock protocol, so the TS
  reclaim-lock helpers have no separate module.
- `process-identity.ts`: `ownProcessStartedAtMs` derives `process.uptime()` from
  `/proc/self/stat` on Linux; other platforms use module first use (no `workerData` host start).
- `lease-keeper.ts`, `terminal-state-gc.ts`: adapted to the native `{pid, startedAtMs}` lease
  record (no token/boot fields); a reused pid is detected by start-time drift.
- `rpc-monitor-render.ts`: the per-batch label set clears at `end_batch` (upstream microtask).
- `restore-digest.ts`: per-monitor results come as `RestoreDigestInput`; the native
  `restore::RestoreDigest` counters are unchanged. The notice renderer registration is not ported.
- `orphan-reaper.ts`: Windows evidence (CIM) is not read; win32 never kills on confirmation.
