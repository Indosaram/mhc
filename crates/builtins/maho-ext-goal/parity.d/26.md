Store reference uses concrete maho-core SessionManager; extension-context integration
still requires shared SessionManager to expose session_dir (currently absent).
Wait progress ports countdown and bar logic; unknown-source collation uses Rust
lexical order rather than JS localeCompare, and numeric stringification is partial.
UI footer logic is ported; objective previews cut across a UTF-16 surrogate pair
use a replacement scalar because the native String cannot represent lone surrogates.
Elapsed ticker owns a cancelable native one-second timer, render deduplication and
stale-context retirement. Sync is async to surface completed worker failures;
stop returns the canceled handle for cleanup observation. Real-context timing,
resync and retired-context regression coverage and footer QA remain pending.
Prompt templates and live-source stall advice are ported; JS number stringification
for fractional/exponential accounting values remains partial.
Lifecycle resume eligibility, assistant text extraction and blocking-reason mapping
are ported. Continuation delivery/signatures still depend on shared session_dir,
todotools branch state and host action bindings; no substitute traits are introduced.
Monitor argument and admission records use the native context/event types.
The continuing-verdict refinement remains represented by the existing verdict enum
until the monitor consumer is ported.

This is a domain slice, not a completed extension. Persistence has the current
store and migration mechanisms; upstream migration race cases and integer-valued
float JSON inputs need coverage.
Cache metrics, delay policy and durable payloads are ported; compact-token and
local-timezone timestamp formatting remain pending. USD fixed-decimal formatting
uses Rust rounding and still needs exact JavaScript toFixed tie behavior.
Goal format implements elapsed/token labels, human tool output, snapshots and ISO
timestamps for native epoch range; extended JS Date years, toFixed ties and JSON
float output still need parity.
Turn usage uses typed native assistant messages and unsigned integer counters;
upstream unknown-message fractional/negative numeric fields and overflow behavior
remain unported. The upstream extension accounting integration tests are pending.
Store mutations use the existing maho-core serialize_by_key and explicit epoch
seconds for deterministic clock injection. Full upstream store tests remain to be
ported; token counters beyond the JavaScript safe-integer range need parity.
All other source modules remain unported. Existing upstream test files are not claimed as fully ported by these
targeted domain tests.
