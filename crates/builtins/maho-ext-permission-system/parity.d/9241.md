  - `integration.ts`: 77 upstream integration tests covered by 19 tests in `tests/integration_suite.rs` plus 2 tests in `tests/native_persistence.rs`.
- `PermissionRequest` is now crate-local with `original_paths`/`rule_aliases`/`auto_approve_ask`: the tool-facing `maho_tools::ToolPermissionRequest` (custom parsers) keeps only permission/patterns/always and converts via `From`. Adding the fields there would be a cross-lane change in maho-tools.
- index.ts `denyReason` ("The user can edit that entry to allow this call.") has no Rust counterpart: mhc blocks with the bare error text and has no deny provenance.
- read-permission: `src/read_permission.rs` is fully ported and tested in `tests/read_permission.rs` (5 tests covering auto-approval of bundled assets, denial overrides, root list validation, symlinked root defense, and symlinks within roots escaping to outside files).
- grep: a non-ENOENT stat error does not throw (parsers cannot fail here); the literal path is classified instead.
- external-pattern: on non-Unix, std exposes no dev/ino, so identity matching is off and only lexical matching applies.
- Only the mhc-specific headless external_directory message (SD-1, used when the request is not preset-bound) is kept. The "Permission denied by {source}" text was removed: no-UI refusals use the upstream handleNoUI wording.
- The 4351-review-regressions, 4351-resolution-chain, 4351-relative-precedence and 4351-case-sensitive-links suites are not ported case by case; their core cases are covered by tests/canonical_identity.rs.
