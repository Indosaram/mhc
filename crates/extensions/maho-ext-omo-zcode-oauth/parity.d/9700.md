Closing audit against the pinned suites:

- glm-zcode "anthropic wire payloads": three cases were added in `src/index.rs`.
  - `medium_wire_body_uses_adaptive_thinking_with_low_effort`
  - `off_wire_body_omits_thinking_and_keeps_low_adaptive_effort`
  - `toggle_model_off_disables_thinking_without_adaptive_effort`
  Each one sends the registered model config through the real anthropic-messages stream and captures
  the final body with `on_payload`.
- OAuth:
  - The callback validation cases are in `oauth.rs` tests: bare code, port, missing state and state
    mismatch.
  - Refresh re-provisioning without the broker, named-key reuse, cancellation and no-stored-token are
    covered.
  - Secret redaction is covered by `secrets_are_redacted`.
  - HTTP failures report only the status code (`src/oauth.rs:55`), so response bodies, including any
    mixed secrets, are never echoed.
  - The broker endpoint is the hard-coded `BROKER_URL` constant (`src/oauth.rs:7`); no environment
    variable is read for it.
- Models and catalog:
  - Catalog mapping, malformed skip, persisted thinking config and legacy defaults are in `models.rs`
    tests.
  - Live-priority and models.dev fallback, the non-2xx/oversize/empty/no-credential/offline/abort/force
    paths, and snapshot restore are in `live_catalog.rs` and the `index.rs` hybrid-refresh tests.
- Signing: key split, HKDF-HMAC template, cipher decrypt and wrong-key rejection, pow, Ed25519
  verification, gate/handshake caching, disabled gate, rejected handshake fail-open, and the foreign
  provider no-op are all covered in `signing.rs` tests.
- Off-peak:
  - KST window, flash family and marker, availability and ticket protocol, final-poll ready/give-up,
    header routing, override precedence, and marker auth install/fail-open are covered in `offpeak.rs`
    tests.
  - The wire cases (ticket JWT auth without signatures, signed ultra fallback, deferred settle after
    the flag or window closes, retry with the same task identity, single-flight waiters) are covered in
    `index.rs` tests.
- Session id and source headers: the bare stable uuid, the 11 header names, the UA/version coupling,
  the version override, empty-value omission and osCategory are covered.
