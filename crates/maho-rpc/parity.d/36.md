This first module group covers framing, inbound bounds, and streaming event
linearization only. The remaining mode and RPC sources are not yet ported.
The shipped audit has no SOURCE_ROOTS entry for maho-rpc, so its unscoped
success cannot establish full source coverage; the lane evidence must report
the actual source inventory separately.

Command-surface construction and baseline digest behavior are ported. Its
session adapter requires the missing resource-loader/extension-runner accessors.
Custom UI ids are injected by the caller; event batching exposes a scheduling
decision to the host rather than scheduling a JavaScript microtask itself.

RPC command and extension UI types are translated, but response payloads and
session/host event types are not yet fully translated. Do not interpret this partial row as a
complete protocol schema or a working command dispatcher.
