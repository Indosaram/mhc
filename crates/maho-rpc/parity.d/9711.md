`subscribeSessionRecords(session, output, onAbortSource, source)` takes `session.subscribeStructured` as its source
for the structured lane. Natively the record projection runs in `connection_handler::rpc_session_event_record`
(see the NATIVE-DIVERGENCE note in session_record_stream.rs), so `subscribe_structured_session_records` subscribes
`AgentSession::subscribe_structured` (already in maho-core) and runs each event through that same projection,
then the seeded block gate and `json_event::to_seeded_json_event`; block controls pass through as their JSON.

The binding's `writeStructured` is `structured_lane_sink` (None unless `<brand>_ENGINE_SOCKET_COMPACT_UPDATES` is
`1`/`true`), feeding `SessionWriterActor.structured_lanes` while the entry scope is open; the connection
handler's `installSessionSubscriptions` half is `RpcSessionBinding::install_structured_lane`, tagging each
record with the routing `sessionId` and released by `dispose`.

rewrittenFrom", "ends without a terminal capture"), 4272-structured-lane-bridge.test.ts (block-state controls ordered
on the lane, seeded text start and delta offset, no identity keys; writer lanes tagged and closed-scope drop; a
binding without `writeStructured` opens no lane; a session without an internal channel refuses). The flag read
itself (`structured_lane_sink`) is not env-tested: mutating a process env var races parallel tests. Not ported: "late attach" (needs a provider paused mid-stream across two
subscribers) and "end capture failed (LOW a)" (needs an uncloneable argument, a JS-only failure).
