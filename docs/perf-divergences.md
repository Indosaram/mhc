# Intentional performance divergences from upstream senpi

mhc is a file-for-file Rust port of senpi. The entries below are places where
the port **intentionally** implements a cheaper algorithm, data layout, or I/O pattern than the
upstream TypeScript it mirrors. Each one keeps externally observable behavior identical: the same
output, persisted bytes, event order, and error text. Only CPU, memory, allocation, I/O, or
latency cost changes.

Every site carries a source comment of the form:

```rust
// PERF-DIVERGENCE(<upstream file>): <what upstream does>; <what this port does instead>.
```

Search with `rg -n "PERF-DIVERGENCE" crates`. When porting a later upstream change into one of
these files, keep the divergence: re-apply the upstream behavior change on top of the cheaper
implementation instead of reverting to the upstream shape.

Earlier intentional divergences recorded elsewhere: `/resume` newest-first progressive loading
(maho-core parity.d/16.md, 21.md; maho-interactive parity.d/33.md) and the session materialized
entries cache (commit 810805bd).

## Considered and deliberately not changed

These candidates came up in the 2026-10-23 audit but were left matching upstream, for the reason
given. Revisit them only with a measured profile and a test that pins the behavior at risk.

|---|---|
