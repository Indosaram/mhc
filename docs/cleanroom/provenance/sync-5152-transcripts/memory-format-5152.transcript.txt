**Spec ambiguities and what I chose**
- **Empty `expires:` and lists:** YAML reads these as null or a list. Both count as unreadable, so each adds the one warning from 1.2, the same as free text.
- **"Already expired" uses `<=`:** a file counts when its expiry is at or before the import time, which matches the exclusive bound in 1.3.
- **Files with no blocks:** a file is counted in `expired_on_import` only if it has at least one block, i.e. would contribute rows. It's still counted even when all its blocks are skipped as already present.
- **Offsets:** I read the offset hour/minute ranges strictly as written, and bare `+HHMM` without the colon is rejected. Fractions are allowed only after seconds.
- **`metadata_json.expires`:** this holds the parsed string scalar without its quotes and is added only for readable values. The raw value stays in the preserved `frontmatter` either way.
- **`--dry-run`:** `expired_on_import` is judged against the current time, as the spec says, and nothing is written.
